# Portfólio – Matheus Rodrigues da Costa

Site de portfólio pessoal desenvolvido com HTML e CSS puro, sem frameworks ou bibliotecas externas.

## Tecnologias utilizadas

- HTML5
- CSS3 (variáveis, flexbox, grid, animações)
- Google Fonts (Fraunces + DM Mono + Syne)

## Seções

- **Hero** – apresentação e links principais
- **Stacks** – tecnologias e habilidades
- **Projetos** – repositórios do GitHub
- **Experiência** – histórico profissional em timeline
- **Contato** – formas de entrar em contato

## Como rodar localmente

1. Clone o repositório
2. Abra a pasta no VS Code
3. Use a extensão Live Server e clique em **Go Live**
